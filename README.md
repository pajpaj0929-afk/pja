# NUVÉ · AI 광고 포스터 카피 A/B안 제출 보고서

> **Nature in Every Breath.** 매 순간, 자연을 담은 향기.

- **작성자** : 2025101773 박정아
- **사용한 AI** : 챗지피티, 제미나이, 클로드
